# B：展示意图与视听融合

B接收A的真实物体、手部和交互信息，以及D的带时间戳语音事件，输出是否展示、展示哪个实例及何时结束。默认方法为semantic-priority-rest，不调用语言大模型。

## 视觉与状态

从手物关联、相对抬起、接近镜头、稳定呈现和放回趋势积累证据。人物不作为商品候选，单纯检测到物体或手靠近物体不等同于展示。轨迹历史、观测间隔、短期交互记忆及受约束的ID续接用于减少抖动。

状态为NONE、CANDIDATE、SHOWING、ENDING。候选需满足持续性和证据条件后确认展示；短暂缺失允许有限保持，明确放回或超时则退出。视觉可以独立触发。

## 语言绑定与融合

语音提取介绍、展示、描述、停止、换物和属性线索，并绑定语句附近的真实候选。绑定失败、群体介绍、过期指代或其他物品描述不能任意提高某个背景目标的分数。语音可提前确认正在呈现的对象，不能生成检测框。

语言指代的放回判断要求抬起后明确下移并回到观察到的静置区域，不能仅凭相对语句时刻的一次向下移动宣布已放回。基础确认路径与语音增强路径共同工作，保留已确认展示。内部persistent、semantic_priority、rest_aware是同一实现的依赖层次，不是三个需要单独选择的公开版本。

## 实现与参数

src/intent/temporal.py维护状态与轨迹证据，persistent.py处理持续展示，grounding.py处理语言实例绑定，fusion.py累积视听证据，rest_aware.py实现静置区域约束。配置为configs/presentation_intent.json和configs/semantic_priority_fusion.json。分数是规则证据强度，不是校准概率。

## 运行与产物

```bash
python -m scripts.run_refined_b --out outputs/replay
```

从outputs/cache读取已保存A/D输入，无需视频、权重或GPU。输出目录必须未存在。三模式逐帧文件为visual-only.jsonl、audio-only.jsonl、showintent.jsonl，保存在<场景>/<视频>目录；evaluation.json统一保存事件、覆盖、误触发与边界指标。正式产物位于outputs/results。

只有showintent交给C，配合同份A感知按timestamp_ms和track_id联结。纯语音输出没有定位框。完整交付与验收见[C](C.md)，指标与口径见[evaluation](evaluation.md)。

## 主要参数与证据积累

presentation_intent.json定义视觉状态参数：候选至少300ms、展示确认600ms、短暂缺失容忍600ms、轨迹历史窗口4000ms。手物关系最低分0.3，抬起相对位移0.06，放回位置余量0.025。离线入口保留3000ms交互记忆，以容忍手部偶发漏检。

semantic_priority_fusion.json的视觉权重为1、语音权重为2，支持门槛1，联合确认350ms，纯视觉确认600ms。权重是证据组合参数，不能解释为语音在任何场景都占两倍影响。语音提前确认还需满足当前真实目标、呈现候选及指代约束；不足200ms的提前量不单独引入新的语音确认路径。

## 放回与持续展示

物体在空中轻微下移不等于已放回。rest_aware维护轨迹静置高度anchor_y和抬起历史，检测明确下移并回到静置附近后，使旧语句绑定失效。已放回后再次拿起不能凭旧台词自动恢复。

同一次展示中短暂遮挡或受控ID续接不必立即退出；另一方面，历史上曾举过也不能永久维持SHOWING。失检超时、放回和结束均参与退场。内部基础视觉与语言增强路径分别维护状态，输出策略保留已确认的展示并使用符合条件的语音提前量。

## 典型输入情况

| 情况 | 判断方式 |
|---|---|
| 无声拿起并稳定呈现 | 视觉独立确认 |
| 说“看这个”且真实物体正在呈现 | 指代绑定后可提前确认 |
| 桌面介绍多个物品但未展示其中一个 | 群体介绍不任意绑定单个背景对象 |
| 说“下一个介绍”或提到过去物品 | 不直接作为当前展示证据 |
| 物体已放回但识别文本仍有效 | 放回约束阻止旧语句继续支持 |
| 语音有误或未能绑定 | 由视觉路径继续判断 |

## 可追踪输出

每个IntentPacket包含timestamp_ms、state、target_id、score、reason_codes。target_id只对同份A输入有意义；NONE时为空。诊断日志可显示语音来源、绑定状态、候选证据和输出策略，但正式C只需意图与同份感知。

三模式评分仅说明展示时间是否正确，不自动证明绑定实例正确。输出帧时间精度受已有感知时间戳限制；没有原视频也能重放B，但不能据此重新检验A框的视觉质量。
