# 当前方法

## A：视觉感知

闭集四模型输出通用类别，DINO通过固定场景提示输出候选。DINO固定检查点为`IDEA-Research/grounding-dino-tiny`，revision为`a2bb814dd30d776dcf7e30523b00659f4f141c71`。水果提示person/apple/orange，书籍person/book，水杯person/cup/bottle，饮料person/bottle；同场景正负例相同，不输入展示时间和次数。阈值0.25，全帧长边1280、手部裁剪长边960。所有方法共享手部检测、裁剪增强、关系计算、外观匹配和跟踪。DINO只替换物体检测器，不修改B和语音。

## D：语音证据

离线采用Faster-Whisper large-v3，CUDA、beam 5，6秒窗口及1.5秒过去上下文；按媒体时间提交去重后的事件。语言解释器将文本变为展示、否定、放下等有限证据，而不是任意对话推理。纯语音组仅输出时间意图，没有可供镜头追踪的物体框。

## B：离线融合

当前实现`RecoveryOnlyIntentStateMachine`继承`SafeEarlyIntentStateMachine`，再沿用rest-aware及语义融合基类。由手物接近、目标抬起、稳定性和展示区域构成视觉证据，保留视觉确认路径；语音可提前确认视觉候选。提前确认要求当前目标存在且位于展示区域，防止仅凭语音在桌面阶段触发。放下证据促使退出，目标丢失和短时遮挡按时间阈值处理。抬起恢复由`SparseVisualIntentStateMachine`补充到视觉守卫路径。

纯视觉使用同一恢复视觉路径但不读语音；视听使用相同感知输入并读语音；纯语音不读感知框，只共享评分时间轴。该系统以视觉为主、语音辅助，不能把结果解释成通用语义理解已成熟。

## 延时流式

输入按媒体时钟到达，独立视觉和语音进程异步运行；播放端固定缓冲6秒，只使用截止播放时已经可用的证据。继承离线B，观测容忍750→1250ms、证据间隙250→500ms、目标丢失600→1000ms、退出600→900ms；放下100ms、确认600ms保持不变，播放端状态过期容忍500→1000ms。ASR改为base CPU int8、beam 1、4秒窗口；检测10Hz，增强视觉保持1280/960配置。

这是延时流式原型，不保证任意机器都能维持固定延迟。输出帧完整性、实际排队、处理完成时间和额外播放迟滞都应结合`metrics.json`检验；单独播放生成文件不等于已证明实时。预热时间不计入正常播放延迟。

## 结果如何解读

DINO场景先验视听覆盖率95.22%，F1 0.889；YOLO11m视听88.10%，F1 0.935。DINO的F01将三次展示合成一次，覆盖率98.17%仍得到0TP/1FP/3FN；C03被切成三段产生额外FP。不能仅用覆盖率排名。先验DINO语音使覆盖率93.37%→95.22%，不改变事件计数；YOLO11m语音使85.73%→88.10%，F1却略降。融合收益有限，仍是明确限制。

流式YOLO11m纯视觉/纯语音/视听F1分别0.935/0.612/0.935，覆盖率83.13%/47.45%/83.73%。语音时间收益约0.60个百分点，没有事件F1收益。逐视频误差、边界MAE及完整消融见两份正式指标报告。

## 状态更新与时间轴

每个感知包只更新一次状态。候选目标形成后，系统积累手物关系、抬起和稳定展示证据；满足持续时间要求后进入SHOWING，输出对应目标ID。短时遮挡由时间容忍维持，持续丢失或明确放下则结束展示。阈值以毫秒计算，不依赖输入是否恰好固定帧率。

语音不是直接触发镜头的命令。展示语句必须与当前可见且位于展示区域的目标结合，才能提前确认；物品仍在桌面或没有有效候选时，仅有语句不足以进入展示。纯视觉保留同一视觉路径，纯语音则只产生时间状态，不能输出可靠的局部镜头目标。

## 交接镜头模块

逐帧结果包含timestamp_ms、state、target_id及相关展示信息。镜头模块需从同次A输出找到target_id的框，再进行裁剪、平滑与镜头过渡。目标ID不能从另一个检测模型的运行中借用。非SHOWING状态保持全景；B不负责最终缩放倍率和构图。

## 配置与复核

视觉判断参数在configs/presentation_intent.json，融合参数在configs/semantic_priority_fusion.json。缓存重放入口为scripts.run_refined_b，读取outputs/cache中的感知、语音和PTS，输出三种模态及评分。标注只在预测生成后参与评价，不输入状态机。具体命令见README。
