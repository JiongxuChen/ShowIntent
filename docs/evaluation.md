# 评价方法与标注规范

数据用途按场景区分：水果组用于开发；书籍、水杯、饮料三组用于评价。指标仍按四个场景分别报告。

评价覆盖水果、书籍、水杯、饮料四个场景，共22段视频。统一比较纯视觉、纯语音和视听三种模式，逐视频指标与场景汇总见[离线评价结果](evaluation.md)。A04不计入评价。

## 数据与标注文件

水果、书籍的清单和标签位于evaluation/<场景>/dataset_manifest.csv与evaluation/<场景>/annotations.csv；水杯、饮料分别位于evaluation/cups和evaluation/drinks。清单记录视频编号、相对路径、感知来源和评价起止时间。编号对应关系见[evaluation/metadata/video_name_mapping.csv](../evaluation/metadata/video_name_mapping.csv)。

标注采用SHOWING与NON_SHOWING两类，以半开区间[start_ms,end_ms)记录。SHOWING表示讲解者正在呈现物品供观看；单纯拿取、搬动、整理和物体出现在画面中，不自动视为展示。区间应连续覆盖评价范围，事件编号唯一，起点小于终点。

标签依据原视频制定，预测仅在完成推理后进入评分。过渡边界采用原画面中的最佳时间估计。水果与书籍标签已复核，水杯和饮料标签仍待复核；状态记录在标签文件中。

## 时间对齐

timestamp_ms为原媒体时间，严格递增，不要求从零开始。B逐行对应A感知时间戳。评分使用相邻感知包之间的状态，不外推最后一个包之后的时间。视频旋转方向应与生成感知时保持一致。

## 事件与时间指标

连续的SHOWING预测构成展示事件。时间事件按IoU≥0.3进行最大数量一对一匹配，每个标注事件与预测事件最多各匹配一次。

- TP：匹配成功的事件；FP：未匹配预测；FN：未匹配标注。
- Precision=TP/(TP+FP)，Recall=TP/(TP+FN)，F1=2TP/(2TP+FP+FN)。
- 展示覆盖率：标注展示时段内被预测为SHOWING的时间，除以标注展示总时间。
- 误触发时长：标注非展示时段内的SHOWING累计时间；另报告每分钟非展示时间对应的误触发秒数。
- 边界误差：匹配事件的预测起止时间与标注起止时间之差；正数为晚，负数为早，汇总使用绝对误差。

全量覆盖率按展示时间加权，事件指标由合计TP/FP/FN计算；边界MAE按有效匹配边界加权。分母为零时使用null或“—”，不将纯负例的未定义覆盖率写成100%。漏检没有匹配边界，不能计为零误差。

未达到匹配阈值的短预测会同时产生FP与FN，即使它位于真实展示时段内。覆盖率提高也可能伴随展示保持过长，因此需同时比较误触发和事件指标。

## 目标身份与画面质量

时间评价只判断是否应展示，不证明选择了正确物体。正式实例评价需要将track_id按时间区间映射为物理目标，映射未完成时不发布实例正确率。正确类别不等于正确实例。

简易C预览用于直观观察触发效果；构图、目标保留、裁剪抖动、倍率变化及音画同步由C另行评价，交接见[c_handoff](C.md)。

## 复现与记录

```bash
python -m scripts.run_refined_b --out outputs/replay
```

该命令复用随仓库提供的感知和语音缓存，不需要视频或模型权重。输出目录须尚不存在。评价记录标注、输入与配置来源；修改标签、阈值或输入后应重新评分并保存对应配置，确保结果可以追溯。


# 新版离线逐视频指标：纯视觉、纯语音与视听

本表给出离线展示意图方法（`semantic-priority-rest`）的评价结果。数据共22段：水果11段、书籍3段、水杯4段、饮料4段；A04已剔除。

结果来源：[evaluation.json](../outputs/results/evaluation.json)。结果文件包含各场景汇总和逐视频评分。实现说明见[离线B v3](B.md)。

## 三种模式和评价口径

- **纯视觉**：使用相同缓存视觉感知，由`PersistentIntentStateMachine`判断展示，不接收语音证据。
- **纯语音**：使用相同缓存ASR，由`AudioTimeline`配合轻量语言分析判断展示时段。展示/介绍语句开启展示，描述/继续语句可延长，停止/切换语句可结束；默认保持窗口为8秒。不使用画面、手部、物体类别检测或位置证据，输出也没有可供C放大的物体框。它代表当前实现的语音时间基线，不代表所有语音理解方法的上限。
- **视听**：使用相同视觉与ASR输入，由当前v3融合策略判断展示，包含纯视觉保障、语音提前确认、放回判断和旧v2路径保障。

三种模式统一在原离线感知时间戳上评分；纯语音仅借用这些时间戳作为采样时钟，不读取视觉内容。语音按话语结束的内容时间进入判断，不模拟真实ASR计算耗时。因此这是离线内容时间评价，不能用于证明实时能力。

| 指标 | 含义 |
|---|---|
| TP / FP / FN | 正确匹配的展示事件 / 未匹配预测事件 / 漏掉的标注事件；按时间交并比IoU≥0.3做一对一匹配 |
| Precision / Recall / F1 | 事件精确率TP/(TP+FP)、召回率TP/(TP+FN)、F1=2TP/(2TP+FP+FN) |
| 覆盖率 | 标注展示时段内被预测为展示的时间 ÷ 标注展示总时间；也计入未达到事件匹配阈值的重叠时间 |
| 误触发(s) | 标注非展示时段内，仍被预测为展示的累计秒数；事件匹配成功后的开始过早或结束过晚也会计入 |
| 误触发(s/负分钟) | 每分钟非展示时间内的误触发秒数，即60×误触发时间/非展示时间 |
| 起点/终点MAE(ms) | 已匹配事件的开始/结束时间平均绝对误差；不将漏检算成零误差 |

“—”表示分母为零或没有可评价的匹配边界。全程非展示视频没有覆盖率和召回率；若也没有预测展示，Precision和F1均不定义，不能将其写成0分或100分。对这些负例主要看FP和误触发时长。

覆盖率越高不一定整体越好：过长保持可能同时增加覆盖和误触发，也可能把几次展示合成一次，使事件召回下降。以下均为**是否应展示的时间评价**，没有评价物体身份、框的准确性或放大质量。
