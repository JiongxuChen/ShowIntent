# 正式离线五种检测方法：23段完整评价

已采用：YOLO11n、YOLO11m、YOLO11l、RT-DETR-L、场景先验Grounding DINO Tiny。五种配置共享B和语音输入，DINO使用场景候选物品提示。

五种方法使用统一B和语音输入进行评价。

DINO预先获得场景物品信息：水果为apple/orange，书籍为book，水杯为cup/bottle，饮料为bottle；各组另有person。同场景正负例使用相同提示。这是**四个通用闭集检测器与一个场景先验开放词汇检测器的系统比较**，不是等信息条件下的模型能力排名。论文、汇报和表格均需披露该差异。

本表包含五方法×23视频×三模态，共345条逐视频指标及场景/全量汇总。机器可读结果位于`outputs/benchmarks/evaluation.json`。默认YOLO11m另提供逐帧感知和预测，其余模型提供评分及预测展示区间。

运行方式见README，完整数据见`outputs/benchmarks/evaluation.json`。

`visual-only`为纯视觉，`audio-only`为纯语音，`showintent`为视听。先验DINO的纯视觉也获得场景提示；纯语音不接收场景视觉提示，五组结果相同，并非五个语音模型。

事件按IoU≥0.3一对一匹配；覆盖率按真实展示时长加权；误触发时间统计非展示时段；边界MAE仅统计有效匹配边界。负例无覆盖率，无预测及真实事件时F1无定义，记为“—”。这些是时间触发指标，不是检测mAP或构图质量。数据曾参与开发；E04、水杯及饮料沿用现有待复核标注。
