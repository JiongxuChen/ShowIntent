正式流式：继承离线恢复版B的adapted适配，YOLO11m增强视觉、base CPU int8/beam1、4秒音频块、6秒播放缓冲。共23段实际运行，纯视觉与视听直接复用同一批实跑结果；纯语音使用同批实际收到的ASR事件单独评分，共69行逐视频模态指标。

## 三种模态如何保证可比

- 纯视觉：当前流式适配视觉路径，使用相同实际检测采样与播放有效期，不读取语音。
- 纯语音：只使用本次实际收到的base ASR；内容可用源时间=max(话语结束时间，识别实际完成时间－6秒缓冲)。在此前不使用该台词，未换用离线large-v3结果。
- 视听：当前adapted完整B，融合上述本次视觉和语音。
- 统一标签、共同评价区间及实际播放时间网格；纯语音与原两种模式完全相同的起止范围。
- 纯语音是同一ASR运行结果上的消融，不是另起一个不受视觉资源竞争的语音服务。它没有物体框，只能比较触发时段。
## 指标定义与阅读方法

| 指标 | 定义 |
|---|---|
| TP / FP / FN | 时间IoU≥0.3的一对一事件匹配；分别为匹配成功、未匹配预测、未匹配标注 |
| Precision / Recall / F1 | TP/(TP+FP)、TP/(TP+FN)、2TP/(2TP+FP+FN)；F1范围0～1 |
| 覆盖率 | 真实展示时段内预测为展示的时间/真实展示总时间；不能当作物体身份正确率 |
| 误触发(s) | 标注非展示时段内预测展示的累计秒数，包括开始过早或结束过晚 |
| 每负分钟误触发(s) | 60×误触发时间/标注非展示时间 |
| 起点/终点MAE(ms) | 已匹配事件的开始/结束平均绝对误差；不把漏检记成零误差 |

“—”表示无定义：全程负例没有覆盖率和召回率；若没有预测展示，Precision也无定义；既无预测又无标注展示时F1无定义。不能把这些负例写成0分或100分。预测落在真实展示内但太短也可能被记FP，所以FP不等同于非展示误放大。

全量和场景覆盖率按展示时长加权，事件指标先合计TP/FP/FN，边界MAE按有效边界加权，不是逐视频百分比简单平均。

## 与离线对比时的注意事项

离线使用large-v3和密集原视频感知，流式使用base、缩放和稀疏观测及B的中断容忍；这是明确部署适配的效果对比，不是严格同输入实验。离线原始PTS与流式播放网格也不同，直接比较小数差异可能受边界量化影响。使用23段共同网格对比报告比较两者，不能从此表与离线表的微小差值推断模型优劣。

此前核验全部10113帧输出完整，最大额外播放延后约220ms（不含预热）；ASR平均RTF小于1不保证每个窗口都在6秒截止前完成，已收到窗口不代表未收到尾部也被评分。纯语音只使用本次实跑实际可用事件，不人为补齐未来结果。

## 数据范围与限制

- E01～E04按项目约定列作测试集，但曾用于开发；不能作为独立未见测试集结论。
- E04、水杯、饮料仍使用待用户复核的助手标签；水果及原书籍正例已有用户复核。
- 这里是下游展示时间评价，没有计算检测mAP、物理实例正确率、框准确率或C的构图质量。
- 四种模型为预训练闭集检测器，DINO为带场景先验的开放词汇检测器，不据此声称任意物品都能识别。
