# 延时流式：方法与评价

YOLO11m增强视觉、base CPU int8/beam1、4秒音频块、6秒缓冲。视觉采样10Hz，图像长边1280，手部区域长边960。B与离线共享展示证据和双侧低位持物检查，对观测间隙、目标丢失和退出时间作有限容忍。

## 评价方式

下表为当前B在23段已记录输入时序上的受控回放。纯视觉与视听使用相同感知；纯语音使用实际收到的ASR事件，可用源时间=max(话语结束时间，识别完成时间减去缓冲)。三个模式使用相同标注、评价区间和播放网格，不提前使用未来语句。

回放用于检验B的触发判断，不重新执行检测或ASR，也不重新测量吞吐和播放延迟。实测运行的播放记录与运行指标保存在每段目录；D01的当前B回放另存为holding-intent.jsonl和holding-visual.jsonl。其他22段的三模态评分与实测播放一致。outputs/stream/evaluation.json分别保存当前B评分和实测执行汇总。

D01末段为普通持物，应保持全景；当前B不再触发，前两段展示保留。纯语音在该段仍可能产生没有物体定位的展示意图。不得把纯语音状态直接作为物体局部放大的依据。

## 运行与复核

重新执行整套模型见根目录README的延时流式命令。仅复核发布记录：

```bash
python -m src.evaluation.stream --out outputs/new_stream_scores
```

该评分入口优先读取显式保存的B回放轨迹，否则读取实测播放轨迹，并按同一时间网格重算三模态分数。原始日志不被覆盖。
